Transformer WAF: Loss Function, Tokenization, and Dual-Metric Anomaly Detection

Deterministic Zero-Signature Deep Learning Web Application Firewall
Architecture: BERT Masked Autoencoder (6L, d=256, 8H)
Vocab: Byte-Level BPE (993 tokens)

Adaptation: LoRA (Rank=8)
🧠 The Core Idea: The "Fill-in-the-Blank" Game

Traditional WAFs rely on fragile regular expressions that can easily be bypassed with minor encoding tricks. This Transformer WAF is completely signature-free. It has been trained only on benign traffic to learn the normal syntax, vocabulary, and grammar of your website.

Think of it like an expert human reader who has read 20,000+ legitimate requests. If presented with:

"The doctor gave the patient some [BLANK]"
Their brain expects words like "medicine", "advice", or "pills". If the hidden word is indeed "medicine", there is zero surprise (Low Loss • Allowed). But if the blank contains ' OR 1=1-- or <script>, the brain experiences immense shock (High Loss • Blocked). In neural networks, that measure of surprise is Cross-Entropy Loss.

1 Byte-Level BPE Tokenizer Architecture

Standard NLP tokenizers (like BERT WordPiece or GPT sentence BPE) are unsuitable for web firewall security because they frequently merge punctuation into words or replace unseen characters with [UNK]. The WAF uses a custom-trained tokenizer located in waf/model.py with two foundational guarantees:

def train_tokenizer(texts, vocab_size=8000):
    tok = Tokenizer(models.BPE())
    tok.pre_tokenizer = pre_tokenizers.Sequence([
        pre_tokenizers.Split(Regex(r"[A-Za-z]+|\d+|[^A-Za-z\d]"), "isolated"),
        pre_tokenizers.ByteLevel(add_prefix_space=False, use_regex=False)
    ])
    tok.train_from_iterator(texts, trainers.BpeTrainer(
        vocab_size=vocab_size, special_tokens=["[PAD]", "[MASK]", "[CLS]", "[SEP]"],
        initial_alphabet=pre_tokenizers.ByteLevel.alphabet()
    ))
    return tok

Key Architectural Guarantees:

  • Isolated Punctuation Regex: r"[A-Za-z]+|\d+|[^A-Za-z\d]" enforces that letters (products), numbers (102), and individual symbols (', <, ;, =, -) are strictly isolated. Injected operators can never be blended into a neighboring word token.
  • Byte-Level Base Alphabet (No [UNK]): Initialized with all 256 byte values. If an attacker sends raw binary, null bytes (%00), or obfuscated unicode, every byte is guaranteed to map to a valid, deterministic token representation.
  • Vocabulary Saturation: Cap of 8,000 tokens; saturates at 993 distinct tokens across all normalized URL routes.

2 Training Phase Loss Function: Masked Autoencoder

A standard autoencoder with full self-attention simply learns the trivial identity shortcut: it copies the input token straight to the output with near-zero loss, even on dangerous attacks. To force semantic context learning, the model is trained as a Masked Autoencoder (MAE).

Code Implementation (waf/model.py#L131-L132):

# Dynamic masking between 15% and 40% of real tokens
rate = 0.15 + 0.25 * torch.rand(x.size(0), 1, generator=g)
m = (torch.rand(x.shape, generator=g) < rate) & real

logits = model(x.masked_fill(m, MASK))
loss = F.cross_entropy(logits[m], x[m])

Mathematical Formulation:

For an input token sequence $\mathbf{x} = (x_1, x_2, \dots, x_N)$ where a subset of indices $M \subset \{1, \dots, N\}$ are substituted with [MASK], the training loss is the negative log-likelihood of predicting the true tokens from unmasked context $\mathbf{x}_{\setminus M}$:

$$\mathcal{L}_{ ext{training}} = - rac{1}{|M|} \sum_{i \in M} \log P(x_i \mid \mathbf{x}_{\setminus M})$$

The model's probability distribution over the vocabulary of size $V = 993$ is computed via Softmax over output projection logits $\mathbf{z}_i$:

$$P(x_i = j \mid \mathbf{x}_{\setminus M}) = rac{\exp(z_{i, j})}{\sum_{v=1}^{V} \exp(z_{i, v})}$$

During training, the optimizer (AdamW with OneCycleLR) adjusts all parameters so that benign URL paths, queries, and parameter associations yield extremely low cross-entropy loss.

3 Live Inference Loss Function: K=4 Interleaved Passes

During live security inspection, random masking cannot be used because a firewall must be 100% deterministic. To ensure every token is scored without the model seeing itself, the WAF uses $K=4$ Interleaved Passes.

Pass Masked Index Pattern Tokens Evaluated Context Provided to Transformer
Pass 0 $p \equiv 0 \pmod 4$ Positions 0, 4, 8, 12, … All tokens except positions 0, 4, 8, 12
Pass 1 $p \equiv 1 \pmod 4$ Positions 1, 5, 9, 13, … All tokens except positions 1, 5, 9, 13
Pass 2 $p \equiv 2 \pmod 4$ Positions 2, 6, 10, 14, … All tokens except positions 2, 6, 10, 14
Pass 3 $p \equiv 3 \pmod 4$ Positions 3, 7, 11, 15, … All tokens except positions 3, 7, 11, 15

Per-Token Loss Extraction (waf/model.py#L170-L174):

logp = F.log_softmax(model(x.to(dev)), dim=-1)
# For each masked position:
loss_token_i = -logp[batch_idx, pos, target_token_id].item()
$$\ell_i = -\log P\left(x_i \mid \mathbf{x}_{\setminus \{i, i \pm 4, i \pm 8, \dots\}} ight)$$

Within 4 forward passes (~10 ms on CPU), every token $x_i$ receives an exact reconstruction cross-entropy loss value $\ell_i$.

4 Dual-Metric Aggregation: Solving the "Single Quote" Problem

⚠️ Why Simple Averages Fail (The Hospital Fever Analogy)

Imagine a hospital clinic measuring the temperature of 24 patients. 23 patients have a normal temperature of 98.6°F, and 1 patient is in critical septic shock with a 115°F fever. If the hospital administrator only looks at the arithmetic mean: $$ ext{Average} = rac{(23 imes 98.6) + 115}{24} = \mathbf{99.28^\circ ext{F}}$$ The average looks completely normal, and the dying patient is completely ignored!

The Exact Same Failure in Web Attacks:

Consider an injection probe: GET /api/patients?q='

Component Token Count Per-Token Loss ($\ell_i$) Explanation
Benign Structure (GET, /api/patients, ?q=) 23 tokens $pprox 0.10 - 0.20$ Seen thousands of times in training.
Injected Quote (') 1 token $pprox 10.50$ Extreme anomaly. Model has never seen a quote in this position.

If the WAF used a standard average loss:

$$ar{\ell} = rac{(23 imes 0.1) + 10.5}{24} = rac{12.8}{24} = \mathbf{0.53}$$

Since normal long queries naturally reach losses of $0.60 - 0.80$, an average of $0.53$ would allow this SQL injection probe to bypass the firewall completely.

The Two-Alarm Architecture (waf/model.py#L178-L191):

Incoming HTTP Request
│
├──► Alarm 1 (Mean Loss): $\mathcal{L}_{ ext{mean}} = rac{1}{N} \sum_{i=1}^N \ell_i$  ──► Divided by $S_{ ext{mean}} = 2.083$
│
└──► Alarm 2 (Worst Symbol): $\mathcal{L}_{ ext{sym}} = \max_{i \in ext{symbols}} \ell_i$ ──► Divided by $S_{ ext{sym}} = 6.665$

Final Anomaly Score = $\max\left( rac{\mathcal{L}_{ ext{mean}}}{S_{ ext{mean}}}, \;\; rac{\mathcal{L}_{ ext{sym}}}{S_{ ext{sym}}} ight)$
$$ ext{Anomaly Score} = \max\left( rac{\mathcal{L}_{ ext{mean}}}{2.0829}, \;\; rac{\max_{i \in ext{symbols}} \ell_i}{6.6645} ight)$$

Where $S_{ ext{mean}} = 2.083$ and $S_{ ext{sym}} = 6.665$ are the empirical 98.5th percentiles of clean traffic computed during 5-fold cross-validation. This normalizes both terms so that 1.0 is the exact alert threshold.

Verdict on Single Quote Probe:

$$ ext{Score} = \max\left( rac{0.53}{2.083}, \;\; rac{10.50}{6.665} ight) = \max(0.25, \; \mathbf{1.58}) = \mathbf{1.58}$$

Because $1.58 > 1.20$ (Threshold), Alarm 2 immediately drops the connection and returns HTTP 403 Forbidden!
